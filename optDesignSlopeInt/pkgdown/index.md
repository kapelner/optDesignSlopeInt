# optDesignSlopeInt <img src="man/figures/logo.png" align="right" height="139" alt="optDesignSlopeInt hex logo" />

`optDesignSlopeInt` helps practitioners optimally design experiments that
measure the slope divided by the intercept of a linear model, and provides
confidence intervals for that ratio.

## Installation

Install the CRAN release with:

```r
install.packages("optDesignSlopeInt")
```

Install the development version from GitHub with:

```r
# install.packages("remotes")
remotes::install_github("kapelner/optDesignSlopeInt", subdir = "optDesignSlopeInt")
```

## Reference

Kapelner, A., Krieger, A. and Blanford, W. J. (2016). Optimal Experimental
Designs for Estimating Henry's Law Constants via the Method of Headspace
Analysis. https://arxiv.org/abs/1604.03480
